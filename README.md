# EduEntorno

EduEntorno es una herramienta interactiva desarrollada en Shiny, diseñada para visualizar y analizar indicadores contextuales relacionados con la educación en Perú. Permite explorar datos desagregados a nivel regional sobre factores como deserción escolar, pobreza, coeficiente de Gini, empleo, características docentes y de escuelas obtenidas de bases de datos públicas. Además, se ofrece un análisis cruzado entre estos factores contextuales y el rendimiento educativo a nivel regional, facilitando una comprensión integral de cómo el entorno socioeconómico y educativo se relacional con los logros de aprendizaje.
